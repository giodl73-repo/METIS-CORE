Status: candidate implementation qualified; see RELEASE.md and ROLES_REVIEW.md. Exact default/live gates still control publication and TRACKER advancement.

and retain original/current/LF-copy/request/report exports. Drawing uses vertex
index layout, not a geographic or optimized layout. No JavaScript partitioner.
